Zimsmith 0.1.3 preview.
Windows source builds now use a portable MD5 backend and skip Unix-only memory-map advice.
Queued crawl requests recheck server cooldowns extended while they wait. Sequential page and asset requests keep their configured or robots-declared spacing even when scheduling or disk bookkeeping runs late.
Recognized static CDN assets remain free of artificial page delays, while robots rules and server backoff still apply.
Includes the GPL-3.0 license and the GitHub-hosted update feed.
This release uses the same signing key as public 0.1.2 APKs and can update them in place. Earlier private development-signed APKs use a different key; export archives before replacing those installations.
